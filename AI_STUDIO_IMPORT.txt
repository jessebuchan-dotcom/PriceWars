PRICE WARS — IMPORT INTO GOOGLE AI STUDIO
=======================================

This ZIP contains the COMPLETE SOURCE PROJECT, not a one-page prompt or a mock-up.

1. Extract the ZIP to a computer.
2. Create a PRIVATE GitHub repository named "price-wars-business-simulation".
3. Upload the project files to the repository (including src/, server/, shared/, tests/, package.json, Dockerfile and README.md). Do NOT upload .env, any teacher recovery keys or other secrets.
4. Open https://aistudio.google.com/ and select Build.
5. Use Add files (+) → Import from GitHub, select your repository, and import the project.
6. Paste the instruction below into Build mode.
7. When the code imports, ask AI Studio to install dependencies, run `npm run check`, `npm test` and `npm run build`, then resolve anything that fails.
8. Complete Firestore and Cloud Run hosting as outlined in README.md, with a protected teacher setup PIN. Test with multiple devices before using it in class.
